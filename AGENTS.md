## What this repo is

Full macOS dev environment. One command from a fresh machine:
```bash
curl -fsSL https://raw.githubusercontent.com/mahi160/setthemacup/main/bootstrap.sh | bash
```

`bootstrap.sh` (the only shell entry point) installs Xcode CLT, clones the repo to `~/.setup`, installs fnm → Node LTS → pnpm, then hands off to the Node installer (`installer/index.ts`), which shows a checklist. Afterwards, `setup` (on PATH) re-runs it. Docs page: `docs/index.html` (GitHub Pages), generated by `pnpm run docs`.

## Installer — the checklist

Run order is `installer/steps/index.ts`. Homebrew always runs; the rest are checkboxes, all on by default.

| id | Step | What |
|---|---|---|
| `homebrew` | Homebrew | install brew, `brew shellenv` in `.zprofile`, fix `share/` perms (required — failure aborts) |
| `cli` | CLI tools | formulae from `data/apps.ts`, one batched install |
| `dotfiles` | Dotfiles + theme | oh-my-zsh + plugins, stow packages (conflicts → `~/.setup-backup/<date>/`), theme links |
| `git` | Git + SSH | `~/.gitconfig.local` (identity + work `includeIf`), stow ssh, keys with passphrase, optional `gh` upload |
| `nvim` | Neovim | LazyVim headless sync + clean |
| `ai` | AI | `pnpm add -g` pi (unpinned) + skills from `data/skills.ts` (`--agent pi` → `~/.agents/skills`) |
| `extras` | Extras | link `bin/*`, compile Swift, Pokemon bg, pi icon, SMB + weekly LaunchAgents (`com.setthemacup.*`) |
| `flowd` | flowd | install `fw`, clone journal, restore db from `~/flowd-backup.zip`, generated config |
| `apps` | GUI apps | casks from `data/apps.ts` (taps first) |
| `macos` | macOS settings | `data/defaults.ts` (only drifted values written), ⌘Space, Caps→Ctrl, chime, display |

```bash
setup                 # checklist
setup --yes           # everything, no prompts
setup --only git,nvim # Homebrew + these
setup --dry-run       # print commands, change nothing
setup --list          # status of every step
pnpm test && pnpm typecheck
```

**Step contract** (`types.ts`): `check()` returns done/partial/missing and must be read-only; `run()` must be safe to repeat. Wrap each sub-action in `ctx.task(title, fn)` (spinner, failures recorded, never thrown); use `ctx.interactive` for anything that needs the terminal. System changes go through `ctx.sh.run` (logged, skipped under `--dry-run`); read-only queries use `ctx.sh.capture`. Generated files go through `lib/fs.ts` `writeFile`/`link`.

**Adding a step:** create `installer/steps/<name>.ts` exporting a `Step`, add it to `steps/index.ts` in run order, add its id to `HELP` in `plan.ts`, run `pnpm run docs`.

## Dotfiles — stow rules

- Stowed with GNU stow from `dotfiles/` into `$HOME`
- `.stow-global-ignore` uses **Perl regex** (not shell globs):
  - `\.DS_Store$` not `*.DS_Store`
  - `.*\.md$` not `*.md`
  - `LICEN[CS]E$` covers both spellings
- `.md` files are ignored → they never land in `$HOME` — safe to add docs anywhere in dotfiles
- Add new dotfile package: create `dotfiles/pkgname/` mirroring the `$HOME` structure, add it to `PACKAGES` in `installer/steps/dotfiles.ts`. Use `noFolding` when tools write into the target dir

## zsh

- **oh-my-zsh**, cloned to `~/.oh-my-zsh` (untracked). `ZSH_CUSTOM=~/.config/zsh`.
- Tracked: `dotfiles/zsh/.config/zsh/themes/mahi.zsh-theme`, a two-line prompt that replaces starship. It uses ANSI colors only and OMZ's async git prompt; keep the literal `$(git_prompt_info)` / `$(git_prompt_status)` in `PROMPT`.
- External plugins (zsh-autosuggestions, zsh-syntax-highlighting, zsh-completions) are cloned into `~/.config/zsh/plugins/` and gitignored. The zsh package is stowed with `--no-folding` so those clones never land in the repo.
- Bundled plugins: git, brew, fnm (autostart, use-on-cd), fzf (Ctrl-R history), z, gh, sudo, copypath, extract, colored-man-pages. zsh-syntax-highlighting stays last.
- zsh-completions goes on `fpath` before OMZ loads, not in `plugins=()`. OMZ owns `compinit`.
- `SETTHEMACUP` env var always points to `~/.setup` (set in `.zshenv`)

## tmux

- **No TPM. No plugins. Fully native.**
- Status bar widgets are `bin/` scripts linked into `~/.local/bin/`: `tmux-git`, `tmux-nowplaying` (uses `nowplaying-cli`), `claude-tmux`
- Popups: `pi-qna`, `quick-note`, `quick-learn`
- `fw start` (flowd) runs when tmux starts, if `fw` is installed
- Plugin format strings (`#{battery_icon}` etc.) have **no provider** — never use them
- Clipboard: native `pbcopy` via `copy-pipe-and-cancel`
- `escape-time 10` — do NOT set to 0
- `status-interval 5` — drives nowplaying refresh
- Theme: `theme.conf` symlink to `theme.d/<name>.conf` (see Themes) — color vars: `#{@thm_bg}` `#{@thm_fg}` `#{@thm_acc1}`–`4` `#{@thm_gray}` `#{@thm_darkgray}`
- Reload: `C-a r`

## pi

- Config: `~/.pi/agent/` (whole directory stowed from `dotfiles/pi/`)
- Packages are declared in `settings.json` under `"packages"` — pi auto-installs missing ones on startup (the installer only installs pi itself)
- **Pin npm packages to an exact version** (`npm:pkg@1.2.3`). Unpinned `npm:` floats, and provider-overriding extensions see your OAuth token
- MCP servers live in `mcp.json` and use pi's built-in MCP support. Do not install `pi-mcp-adapter`: it replaces the built-in support
- Anthropic Claude Pro/Max OAuth compat comes from pi itself (Claude Code headers and tool-name casing in pi-ai) plus the local `extensions/pi-claude`, which renames non-Claude-Code tools to `mcp__pi__<name>` on the wire and maps calls back. Set `PI_CLAUDE_CODE_USE_DISABLE_TOOL_RENAME=1` to send the original names
- `extensions/pi-permissions` never prompts: writes are allowed inside cwd, `~/.pi`, and temp dirs; everything else is read-only; secret paths are always blocked
- `extensions/pi-orca` (on by default, `/orca` toggles) adds a `delegate` tool: the Opus orchestrator hands subtasks to fixed roles (`scout`/`tester` on Haiku, `coder`/`reviewer` on Sonnet). It shares the RPC child runner `extensions/lib/child-pi.ts` with pi-spawn; that folder has no `index.ts`, so pi never loads it as an extension. Children get `PI_CHILD=1`, which disables pi-orca inside them
- `extensions/pi-recap` shows a short Haiku-written recap when you return to an idle session (terminal focus regained after 3+ min away; first keypress after 3+ min idle when the terminal sends no focus events). It never uses the session's model. `/recap` recaps now; `/recap off|on` persists in the gitignored `~/.pi/agent/recap.json`
- Local extensions import only host-provided modules (`@earendil-works/*`, `typebox`), so they need no `package.json` or `node_modules`
- `models-store.json`, `web-search-cache/`, `auth.json`, `mcp-auth.json`, `trust.json`, `sessions/`, and `npm/` are pi-managed and gitignored

## Themes

- `theme` (`bin/theme`) cycles Gruvbox Material, Kanagawa Wave, and Everforest Dark Hard; `theme <gruvbox|kanagawa-wave|everforest>` sets one; `theme status` prints the current one.
- State: `~/.config/theme`. Readers: nvim, `tmux-git`, `claude-tmux`, and the pi-stats report.
- Ghostty, tmux, and lazygit load a gitignored symlink (`theme`, `theme.conf`, `theme.yml`) that points to a tracked file in their `theme.d/`. pi uses a gitignored copy, `themes/current.json`, because a pi theme file name must equal its `name`.
- Live reload covers tmux, running nvim instances (through their sockets), pi (hot reload), and Ghostty (an AppleScript keystroke of cmd+shift+,, which needs Accessibility permission).
- The Dotfiles step runs `bin/theme <current> --no-reload` to create the links; the default theme is Kanagawa Wave.

## key conventions

| Thing | Convention |
|-------|-----------|
| Colors | Always use `@thm_*` vars in tmux; every themed color must exist for every theme (see Themes) |
| Paths | Use `~` or `$HOME` — never hardcode `/Users/mahi` |
| Shell patterns | Use `case ":$PATH:"` guard for PATH additions |
| Regex in stow | Perl regex — `.*\.ext$` not `*.ext` |
| Brew taps | Full path `owner/tap/name` in `apps.ts`; the installer taps it first |
| New commands | Add an executable to `bin/` (no extension); Extras links it into `~/.local/bin/` |
| Paths in config | Use `~/.` not `/Users/mahi/` |
| Scripts | `set -euo pipefail`; find the repo via `$SETTHEMACUP` (they run through symlinks, so not `$0`) |

## hard rules

- **No starship, zoxide, atuin** — the prompt is the OMZ theme, `z` is the OMZ plugin, history is fzf Ctrl-R
- **No TPM** — tmux is fully native; status bar uses `~/.local/bin/` scripts
- **No shell setup scripts** — setup logic lives in `installer/` (TypeScript); `bootstrap.sh` is the only shell entry point
- **No hardcoded `/Users/mahi`** anywhere
- **No private data in the repo** (it is public): emails, names, work hosts/repos/URLs, LAN IPs, notes vault names, private repo names. They go in `~/.config/setthemacup/private.env` (template: `private.env.example`), loaded by the installer and `.zshenv`. Machine-local aliases go in `~/.config/zsh/local.zsh`
- **No `prefix2 none`** in tmux — invalid key, silently errors
- **No `escape-time 0`** in tmux — use 10ms minimum
- **No `*.ext` in stow ignore** — use Perl regex `.*\.ext$`
- **No `background-blur-radius`** in ghostty — use `background-blur = N`
- **No plugin format strings in tmux** (`#{battery_icon}` etc.) without a provider
- **Do not commit or push** unless explicitly asked
