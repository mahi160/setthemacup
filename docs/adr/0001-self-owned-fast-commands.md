# Self-owned fast-commands extension instead of pi-subagents delegation

The 6 personal git-workflow commands (`/commit`, `/pr`, `/pr-check`, `/standup`, `/review`, `/test`) move off `pi-subagents`' event-bridge delegation (`extensions/fast-commands.ts` firing `prompt-template:subagent:request` and waiting for a response event) onto a small self-owned direct-spawn extension. `pi-subagents` is a ~55k-LOC third-party framework built for general orchestration (chains, parallel, async, watchdog, scheduling); for a fixed set of 6 personal commands it was more indirection than value, and that indirection was implicated in a real bug where a bare `/commit` surfaced the subagent's confused clarifying text as its final answer instead of committing. The self-owned extension restores full ownership of the flow (live progress widget, an `ASK:`-sentinel bridge to the real `ask_user` overlay for genuine ambiguity, direct function call instead of an event round-trip) while `pi-subagents` stays installed and untouched for everything else that already depends on it (the generic `subagent` tool, the `research` and `code-review` skills, ad-hoc chain/parallel/async work).
