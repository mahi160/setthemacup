setthemacup

One command from a fresh Mac to my full dev environment. Everything it installs and changes is on this page.

curl -fsSL https://raw.githubusercontent.com/mahi160/setthemacup/main/bootstrap.sh | bash
StepsPackagesmacOS settingsDotfilesKeybindsPrivate valuesRe-running

What it does

Homebrew always runs; everything else is a checkbox, all on by default. Each step checks what's already done, so re-running is safe.

  1. 1

    Homebrew

    homebrewalways runs

    Package manager everything else installs with

    • Installs Homebrew to /opt/homebrew (non-interactive, uses the sudo session)
    • Adds brew shellenv to ~/.zprofile
    • Removes group write on /opt/homebrew/share so oh-my-zsh's compaudit stays quiet
  2. 2

    CLI tools

    cli

    git, neovim, tmux, fzf, lazygit, gh, … (Homebrew formulae) + pnpm globals (pi)

    • Installs 19 formulae from installer/data/apps.json in one batched brew install
    • Taps third-party taps first; retries one by one if the batch fails
    • Git: git, gh, git-delta, lazygit
    • Editor: neovim, tree-sitter-cli, ripgrep, fd
    • Terminal: tmux, fzf, stow, fastfetch, onefetch, nowplaying-cli
    • Dev: lazydocker, lazysql
    • System: terminal-notifier, mole, openfortivpn
    • pnpm globals (latest, pnpm add -g): @earendil-works/pi-coding-agent
  3. 3

    Dotfiles + theme

    dotfiles

    oh-my-zsh, then link zsh, git, ghostty, tmux, nvim, lazygit, fastfetch, pi configs

    • Clones oh-my-zsh to ~/.oh-my-zsh and zsh-autosuggestions, zsh-syntax-highlighting, zsh-completions into ~/.config/zsh/plugins
    • Links dotfiles/{zsh,git,ghostty,tmux,nvim,lazygit,fastfetch,pi,stow} into $HOME with GNU stow
    • Real files in the way are moved to ~/.setup-backup/<date>/ (paths kept), never overwritten
    • Creates the theme links (theme state in ~/.config/theme, default kanagawa-wave)

    Needs: stow git

  4. 4

    Git + SSH

    git

    Git identity (personal + work via includeIf), SSH keys, optional upload to GitHub

    • ~/.gitconfig is stowed from dotfiles/git (delta pager, sane defaults, no identity)
    • ~/.gitconfig.local gets [user] from private.env plus an includeIf that switches to the work identity under $WORK_DIR
    • ~/.ssh/config is stowed; work host alias goes in ~/.ssh/config.local
    • Generates ed25519 keys (asks for a passphrase, stored in the macOS Keychain)
    • Optionally logs in with gh and uploads each key to its GitHub account

    Needs: gh stow

  5. 5

    Neovim

    nvim

    LazyVim plugins synced headlessly

    • Runs nvim --headless "+Lazy! sync" then "+Lazy! clean" against the stowed LazyVim config
    • Mason installs language servers on first interactive start

    Needs: neovim git ripgrep fd tree-sitter-cli

  7. 7

    Extras

    extras

    Helper commands, Swift tools, Pokemon background, SMB auto-mount, weekly cleanup jobs

    • Links every file in bin/ into ~/.local/bin (dev, note, vpn, theme, pokemon-bg, setup, tmux widgets, …)
    • Compiles src/swift/*.swift into ~/.local/bin when the source changed
    • Downloads a starter Pokemon for the Ghostty background and builds the pi notification icon
    • One LaunchAgent per SMB share in private.env (mounts on login via Finder + Keychain)
    • Weekly LaunchAgents: pi-prune, fnm multishell cleanup, brew/pnpm cache cleanup (replaces crontab)
    • Daily setup --sync: anything you brew install, pnpm add -g or skills add by hand lands in the manifest (category Inbox); removals drop out; you get a notification and commit when ready
  8. 8

    flowd

    flowd

    Coding-time tracker: install fw, restore the journal, AI summaries with Haiku

    • Installs fw from github.com/mahi160/flowd releases into ~/.local/bin (no sudo)
    • Clones the journal repo (FLOWD_JOURNAL_REMOTE in private.env) to ~/.local/share/flowd/journal
    • Restores flowd.db from ~/flowd-backup.zip if the journal has none (never overwrites)
    • Writes ~/.config/flowd/config.yaml with ai_command: pi -p --model anthropic/claude-haiku-5-5:low
    • tmux.conf starts the daemon (fw start) whenever tmux starts

    Needs: tmux git

  10. 10

    macOS settings

    macos

    106 system defaults (Dock, Finder, keyboard, trackpad, …), Caps Lock → Control, display scaling

    • Applies the defaults table in installer/data/defaults.ts (Dock, Hot corners, Spaces & windows, Finder, Dialogs, Keyboard, Trackpad, Screenshots, Menu bar, Speed & appearance, Privacy & noise); only drifted values are written
    • Restarts only the affected apps (Dock, Finder, SystemUIServer)
    • Frees ⌘Space from Spotlight for Tinycast
    • Caps Lock → Control via a hidutil LaunchAgent (no Karabiner)
    • No startup chime (nvram, needs sudo)
    • Display scaling "More Space": the largest HiDPI mode of the built-in display

Keeping the lists in sync

A daily job (setup --sync) compares what's installed with the previous run. Anything you brew install, pnpm add -g or npx skills add by hand is appended to the JSON lists under the Inbox category; anything you uninstall is dropped. You get a notification and commit when ready. Never-sync names live in installer/data/sync-ignore.json.

By hand (no reliable key)

  • System Settings → Appearance → Liquid Glass: drag the slider to the most opaque setting
  • System Settings → Apple Intelligence & Siri → turn off Apple Intelligence if unused (frees several GB)
  • System Settings → Notifications → turn off "Summarize Notifications"
  • System Settings → Menu Bar → untick the system items you never use
  • System Settings → Spotlight → untick categories you don't need; add code folders to Search Privacy
  • System Settings → General → Login Items & Extensions → remove what you don't need
